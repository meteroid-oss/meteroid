# Security Policy

## Supported versions

Security fixes are released in new versions of Meteroid. We recommend running the latest version.

## Reporting a vulnerability

Please report vulnerabilities privately to [security@meteroid.com](mailto:security@meteroid.com), not in
public issues or pull requests. Include what you found, how to reproduce it, and the version you tested.

We will acknowledge your report, keep you informed while we work on a fix, and credit you when it is
released if you wish.

We do not run a bug bounty program.
